# Family Story — пилот

Простая страница для пилота: человек получает ссылку, слушает вопрос о своей жизни и отвечает голосом. Ответ он сам отправляет в WhatsApp или Telegram через меню «Поделиться». Сервер и регистрация не нужны.

## Как это работает

1. **Вы создаёте ссылку.** Откройте страницу без параметров, введите своё имя, как зовут рассказчика (например, «Мама») и язык вопросов: русский, казахский или английский.
2. **Отправляете ссылку** кнопкой WhatsApp или Telegram.
3. **Рассказчик открывает ссылку**, нажимает большую кнопку и говорит. Можно прослушать вопрос, перезаписать ответ, пропустить вопрос и отметить, кому можно показать ответ: «Семье сейчас» или «Только позже».
4. **«Отправить ответ»** открывает меню «Поделиться» с аудиофайлом. Человек выбирает ваш чат. Если меню недоступно (например, на компьютере), файл скачивается.

Имя файла содержит номер вопроса и отметку приватности, например `Мама_q03_now_2026-11-05.m4a`.

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | Каркас страницы |
| `styles.css` | Оформление: крупный шрифт, большие кнопки, тёмная тема |
| `questions.js` | Тексты интерфейса и вопросы на трёх языках — редактируйте вопросы здесь |
| `app.js` | Логика: создание ссылки, запись, отправка, прогресс |

## Запуск на своём компьютере

Микрофон в браузере работает только на `localhost` или по HTTPS.

```bash
cd ~/Documents/family-story-app
python3 -m http.server 8000
```

Откройте http://localhost:8000 в Chrome или Safari.

## Публикация (GitHub Pages)

1. Загрузите репозиторий на GitHub (команда ниже).
2. На GitHub: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту страница будет доступна по адресу `https://<ваш-логин>.github.io/family-story-app/`.

```bash
cd ~/Documents/family-story-app
gh repo create family-story-app --private --source=. --push
```

Для бесплатного GitHub Pages репозиторий должен быть публичным (`--public`), либо разверните его на Vercel.

## Что проверить перед пилотом

- Казахские тексты в `questions.js` — проверьте носителем языка.
- Запишите тестовый ответ на iPhone и Android и отправьте его в WhatsApp и Telegram.
- Озвучка вопроса использует голос телефона; казахского голоса на многих телефонах нет, тогда кнопка сообщит об этом.

## Что мерить в пилоте (5 родителей)

- Сколько людей открыли ссылку.
- Сколько ответили на первый вопрос.
- Сколько ответили на 4+ вопроса.
- Средняя длина ответа и насколько ответы откровеннее, чем разговор вживую.

## Следующие шаги

- Вопросы голосом самого ребёнка (записанные заранее) вместо синтезированного голоса.
- ИИ-интервьюер с уточняющими вопросами («как звали учителя?», «какого цвета был дом?»).
- Хранение ответов в общем семейном архиве вместо пересылки файлов.
- Карточка жизни: люди, места, годы, предметы, любимые фразы.
- Визуализация: комикс и анимация с настоящим голосом.
